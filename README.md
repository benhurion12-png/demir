# ABIDE MRI Viewer

Локальное веб-приложение для просмотра настоящих структурных 3D MRI из набора ABIDE I. Поддерживает NIfTI-файлы `.nii` и `.nii.gz`, использует WebGL2 и [Niivue](https://niivue.com/) непосредственно в браузере.

MRI и фенотипический CSV не отправляются на сервер: приложение получает браузерные объекты `File`, а Niivue самостоятельно распаковывает и разбирает NIfTI. В проекте нет демонстрационных или фиктивных медицинских данных.

## Возможности

- загрузка одного или нескольких `.nii` / `.nii.gz` через drag-and-drop или диалог;
- аксиальная, сагиттальная и корональная 2D-проекции, MPR и 3D volume rendering;
- навигация мышью и отдельными слайдерами X/Y/Z;
- настройка яркости, контраста и цветовой схемы;
- отображение dimensions, voxel spacing, orientation, datatype и affine 4×4;
- импорт `Phenotypic_V1_0b_preprocessed.csv` и сопоставление по `SUB_ID`;
- отображение группы ASD / Control, возраста, пола и центра при наличии полей;
- переключение между локально загруженными участниками;
- тёмная и светлая темы, адаптивный интерфейс.

## Запуск в Docker

Требуется Docker с поддержкой Compose.

```bash
docker compose up --build
```

После сборки откройте:

```text
http://localhost:3000
```

Остановка:

```bash
docker compose down
```

## Локальная разработка

Требуется Node.js 22+.

```bash
npm ci
npm run dev
```

Production-проверка:

```bash
npm run typecheck
npm run build
npm start
```

## Использование

1. Нажмите **Добавить MRI** или перетащите один или несколько файлов `.nii` / `.nii.gz` в область загрузки.
2. Выберите участника в списке слева.
3. Переключайте режимы **Axial**, **Sagittal**, **Coronal**, **MPR** и **3D** над окном просмотра.
4. Для фенотипических данных загрузите `Phenotypic_V1_0b_preprocessed.csv`.
5. `SUB_ID` извлекается из имени MRI по последней последовательности минимум из пяти цифр. Если имя имеет другой формат, отредактируйте поле `SUB_ID` справа.

Стандартные числовые значения ABIDE I отображаются как:

- `DX_GROUP=1` — ASD, `DX_GROUP=2` — Control;
- `SEX=1` — мужской, `SEX=2` — женский.

Поддерживаются поля `AGE_AT_SCAN` (или `AGE`) и `SITE_ID` (или `SITE`). CSV индексируется только в памяти вкладки.

## Управление Niivue

- колесо мыши — переход между срезами;
- левая кнопка — установка перекрестия;
- правая кнопка и перетаскивание — интерактивное окно интенсивности;
- в режиме 3D перетаскивание вращает объём.

Слайдеры под canvas синхронизированы с положением перекрестия. Панель **Визуализация** меняет окно интенсивности и colormap активного тома.

## Требования и ограничения

- нужен современный браузер с WebGL2 (актуальные Chrome, Edge, Firefox или Safari);
- доступная память браузера должна соответствовать размеру распакованного 3D-тома;
- приложение предназначено для исследовательского просмотра, а не для клинической диагностики;
- нейросеть и классификация намеренно не включены на этом этапе.

Если canvas не запускается, проверьте, что аппаратное ускорение браузера и WebGL2 включены. При ошибке чтения убедитесь, что файл действительно является валидным NIfTI, даже если его расширение выглядит корректно.

## Стек

- Next.js App Router + TypeScript;
- Tailwind CSS + локальные компоненты shadcn/ui;
- `@niivue/niivue` 0.69 для NIfTI и WebGL2;
- Papa Parse для локального CSV;
- multi-stage Docker build и standalone Next.js runtime.
